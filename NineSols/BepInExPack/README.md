# BepInEx pack for Nine Sols

BepInEx 5 mod loader plus Configuration Manager, ready for Nine Sols. Ships the config fix the game needs (`HideManagerGameObject = true`).

## Install

Download on [Nexus Mods](https://www.nexusmods.com/ninesols/mods/17). Extract into the game folder and play.
