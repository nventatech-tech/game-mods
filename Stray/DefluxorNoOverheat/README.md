# Defluxor No Overheat

[![Nexus Mods](https://img.shields.io/badge/Stray-Nexus%20Mods-E6832B?logo=nexusmods&color=E6832B&label=Nexus%20Mods)](https://www.nexusmods.com/stray/mods/390)

![cover](screenshots/cover.png)

The Defluxor never overheats — keep it on as long as you want. Vanilla on/off button, keyboard and controller, no game files modified.

## ✨ Features
- Defluxor never builds heat, use it forever
- Turn it on/off with the normal in-game button — keyboard and controller
- No game files modified; delete the extracted files and the game is 100% vanilla
- A small Lua script sets the drone's heat build-up to zero while the game runs

## 📦 Install
Main file (recommended): extract everything into `Stray\Hk_project\Binaries\Win64`. Includes UE4SS 2.5.2 already configured for Stray (the current UE4SS release crashes this game). Already have a working UE4SS setup? Extract the mod-only zip into `Win64\Mods` and add `DefluxorNoOverheat : 1` at the top of `mods.txt`. Linux/Steam Deck: launch option `WINEDLLOVERRIDES="dwmapi=n,b" %command%`.
