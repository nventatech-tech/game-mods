# BepInEx for Cuphead

BepInEx 5.4.23.5 mod loader, ready for Cuphead. Required by Cuphead Double Assist, Cuphead UltraWide and other BepInEx mods.

## Install

Download on [Nexus Mods](https://www.nexusmods.com/cuphead/mods/173). Extract into the game folder and play.
