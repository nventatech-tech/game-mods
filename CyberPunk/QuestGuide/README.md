# QuestGuide

Press U for a native-UI quest guide: main story, ending-affecting side jobs and cosmetic content, with live states, search and one-click tracking.

![QuestGuide](screenshots/cover.png)

## Features

- Press U - full quest guide in-game
- Main / ending-affecting / cosmetic categories
- Live states, filters, search, one-click track
- English & PT-BR

## Install

Download on [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/31784). Extract into the game root folder (the one with `bin`, `archive`, `r6`) or install with Vortex / Mod Organizer 2.
