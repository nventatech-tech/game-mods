# EnemiesEvolve

Makes enemies STRONGER instead of MORE: buffs each enemy's stats instead of spawning extra enemies. Flat or per-wave scaling, configurable in-game.

![EnemiesEvolve](screenshots/preview.png)

## Features

- Stat buffs instead of extra spawns
- Flat or per-wave scaling modes
- Fully configurable in Options > Mods

## Install

Download on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3769878400). Subscribe on the Steam Workshop - Brotato installs it automatically. Requires the Brotato ModLoader.
