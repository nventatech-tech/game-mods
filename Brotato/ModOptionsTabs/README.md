# ModOptionsTabs

Sidebar for the ModOptions menu: a list of mods on the left - click one, see only its settings. No more one giant stacked list.

![ModOptionsTabs](screenshots/preview.png)

## Features

- One button per configurable mod, alphabetical
- Only the selected mod's settings on screen
- Fixes 16:9 cutoff

## Install

Download on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3769887447). Subscribe on the Steam Workshop - Brotato installs it automatically. Requires the Brotato ModLoader.
